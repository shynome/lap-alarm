## 默认语言：英语（en-US）

### 简短说明

```
Loop countdown timer: start, pause and stop right from the lock screen.
```

### 完整说明

```
Lap is a repeating countdown timer. Turn "the next N minutes" into one lap, get a ring when it ends, and start the next lap whenever you are ready.

WHAT IT DOES
• Presets of 5, 15, 25 and 45 minutes, plus your own custom values
• Start a lap without unlocking the phone: tap play on the media card in the notification shade or on the lock screen
• Start, truly pause, resume and stop from that same card
• Drag the progress bar to move the remaining time forward or back
• When time is up, Lap loops the system alarm sound, vibrates and wakes the screen; if nobody responds it stops itself after five minutes
• One lap at a time — nothing restarts on its own

WHERE IT FITS
• Pomodoro style focus blocks with a short break in between
• Micro-breaks while working at a screen
• Cooking, workouts, chores and anything else that needs "just N more minutes"

ABOUT PERMISSIONS
• Notifications: show the timer controls on the lock screen and in the notification shade
• Alarms and reminders: ring precisely at the scheduled time
• Foreground service: keep the ringing service running while a lap is active

These permissions are used only for timing and alarms. Lap has no network access and does not collect or upload personal data.

TIP
On some Android skins (for example Xiaomi HyperOS) battery savers may stop background work. Allow Lap to autostart and remove its battery restrictions so the alarm can ring on time.
```

## 简体中文（zh-CN）

### 简短说明

```
循环倒计时与专注计时器：在锁屏和通知栏一键开始、暂停，到点自动响铃。
```

### 完整说明

```
Lap 是一个循环倒计时工具。把「接下来 N 分钟」变成一轮倒计时，到点响铃，然后你可以随时开始下一轮。

主要功能
• 时间档位：内置 5 / 15 / 25 / 45 分钟，也可以自行添加或删除
• 后台启动：不用解锁手机，在锁屏或通知栏的媒体卡片上点播放就能开始一轮
• 完整控制：开始、暂停（真正停止计时）、继续、结束，都在同一张卡片上完成
• 进度可调：拖动播放条，把剩余时间往前或往后调整
• 到点提醒：循环播放系统闹钟铃声、振动并点亮屏幕；如果无人处理，五分钟后自动停止
• 手动循环：每一轮都由你主动开始，不会在你没注意的时候自己继续

适用场景
• 番茄工作法：专注 25 分钟，休息之后再来一轮
• 微休息：长时间盯着屏幕时，每 45 分钟起身活动几分钟
• 做饭、运动、家务等需要「再等 N 分钟」的场合

关于权限
• 通知权限：在锁屏和通知栏显示计时控制卡片
• 闹钟与提醒权限：在预定时间精确响铃
• 前台服务：一轮计时进行中时保持响铃服务运行

以上权限只用于计时与提醒。Lap 没有网络权限，不收集也不上传任何个人数据。

使用提示
部分 Android 定制系统（例如小米 HyperOS）的省电策略可能阻止后台运行。请在系统设置中允许 Lap 自启动，并取消针对它的省电限制，以保证到点正常响铃。
```

## 注意事项

1. **不要复用同一段文字**：简短说明不能是完整说明的第一句，也不能与它完全相同。
2. **不要机翻凑数**：与其给 10 种语言的机翻，不如只保留中英两种真实可用的文本。
3. **不要在简短说明里堆关键词**：Play 的「元数据」政策把关键词重复、无关描述、
   同一句话反复出现都算文字垃圾。
4. **不要在描述里写未经证实的宣传语**（「最好用」「第一名」等），也不要堆 emoji。
5. 修改后如果控制台仍提示该问题，检查是否还有别的语言填了中文原文。
